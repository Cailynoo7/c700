# 小米 C700 猫耳耳麦装饰

按原机照片复刻小米 C700 外壳，再按效果图还原猫耳头梁、左右耳罩和右侧麦克风。原机整体尺寸 82 × 82 × 130 mm，头部为直径 82 mm 球壳。纯机械外观模型，不涉及电子选型或接线。

## 默认建模条件
头部球心距底面 89 mm，球底截平连接收腰底座。镜头窗口、底座曲率和装饰细节依照图片估算并参数化；头梁径向间隙暂取 1.2 mm。背面没有参考，采用连续简洁表面。白色塑料、灰色软垫和黑色麦头用于外观表达。

## 验收
原机参照外包络 82 × 82 × 130 mm，原始球头直径 82 mm。正面还原两张照片中的主要轮廓与装饰。交付参数化组合模型和 STEP 外观模型；安装夹持、端口、散热及云台运动需后续实测。

## 参考
用户上传的原机照片和耳麦效果图；用户明确给出的整体尺寸和球头直径。其余比例是图片估算，不是官方机械测量。
